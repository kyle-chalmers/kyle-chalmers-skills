# Original data-ticket workflow examples

The instruction files, command examples, agents and settings used by the early tutorials are preserved here as historical examples. They are not installed automatically. Copy only the parts you have reviewed into your own project and adapt its paths and tool configuration.

- [CLAUDE.md](CLAUDE.md) imports [AGENTS.md](AGENTS.md).
- [Command examples](commands/)
